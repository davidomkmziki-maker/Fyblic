FYBLIC V1031R1 - TEST EXACT SECURITE STORAGE

ORDRE OBLIGATOIRE
1. Deployer le ZIP V1031 (si ce n'est pas deja fait).
2. Executer FYBLIC_STORAGE_SECURITY_V1031.sql dans Supabase SQL Editor.
3. Verifier la derniere ligne SQL :
   - storage_rls_active = true
   - dangerous_policies_remaining = 0
   - canonical_policies = 7
   - marketplace_private_is_private = true

TESTS FONCTIONNELS
1. Compte A : publier une photo.
2. Compte A : publier une video puis changer sa miniature.
3. Compte A : changer sa photo de profil.
4. Compte A : publier une annonce Marketplace avec media.
5. Compte A : publier une annonce demandant un justificatif prive.
6. Compte A : envoyer une photo ou un fichier dans Messages.
7. Compte B : verifier que les contenus publics du compte A restent visibles.
8. Compte B : ne doit jamais pouvoir modifier ou supprimer un fichier du compte A.

RESULTAT ATTENDU
- Les medias publics restent visibles.
- Chaque utilisateur peut envoyer/modifier/supprimer uniquement ses propres medias.
- Les justificatifs Marketplace restent prives.
- Messages, Assistance et verification vendeur conservent leurs politiques isolees.
