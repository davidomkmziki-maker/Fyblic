FYBLIC V1033 - SECURITE DES FONCTIONS DE PARTAGE

- Base officielle utilisee : V1031. V1032 n'est pas incluse.
- happyad-share-image n'accepte plus une image distante fournie par query string.
- La source est maintenant retrouvee uniquement depuis la publication Fyblic.
- Seuls les medias publics du bucket happyad-media du projet Supabase sont acceptes.
- Taille source maximale : 12 Mo.
- Types acceptes : JPEG, PNG, WebP, GIF et AVIF.
- Limite de 40 millions de pixels avant traitement Sharp.
- Methodes serveur limitees a GET et HEAD.
- Les anciennes URL contenant ?image= sont redirigees vers une URL propre.
- Le dossier .netlify de compilation locale est exclu du ZIP final ;
  netlify/functions reste l'unique source declaree dans netlify.toml.
- Aucun SQL requis.
