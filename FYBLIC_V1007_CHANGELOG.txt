FYBLIC V1007 — MARQUE, PROFIL VISITEUR ET MESSAGES
Date : 12 septembre 2026

1. Identité Fyblic
- Nom visible HAPPYAD remplacé par Fyblic dans les interfaces actives.
- Nom d'accueil Fyblic écrit directement dans le code source HTML/CSS.
- Manifest PWA, titres de pages, partages et textes système actualisés.
- Les anciens identifiants internes HAPPYAD restent compatibles avec Supabase,
  les caches, les sessions et les données déjà enregistrées.
- Section principale « Annonces » renommée « Boutique ».
- « Chat HAPPYAD » renommé « Chat annonce ».

2. Profil visiteur et fullscreen photo
- Clic sur une photo de la grille : ouverture directe du fullscreen existant.
- Un clic simple sur la photo ou le fond ne ferme plus le fullscreen.
- Double-clic/double-tap sur la photo : like direct, sans retirer un like existant.
- Glissement d'album, zoom et déplacement conservés.
- Fermeture visuelle uniquement par la flèche en haut à gauche.

3. Messages
- Nom et avatar dans la liste ouvrent désormais uniquement la conversation.
- Le profil visiteur s'ouvre uniquement depuis le nom ou l'avatar dans l'en-tête
  du message direct entre les deux personnes.

4. Cache
- Version PWA V1007 afin que les téléphones reçoivent les fichiers corrigés.
